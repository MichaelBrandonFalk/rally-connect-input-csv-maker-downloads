How The App Works

The app creates Rally Connect input files by starting with the main WhatsOn spreadsheet and then applying optional, strictly matched enrichment sources.

1. Start With WhatsOn

Rows are created from the WhatsOn input. Direct fields, known aliases, titles, descriptions, categories, dates, ratings, cast, SKUs, and IDs are mapped first.

2. Match Connector

The Connector knowledge base links external references, NewSku values, parent IDs, source media paths, and CVP identifiers when strict matches are available.

3. Apply Avails And CVP

Avails supplies VOD date windows and selected IDs. CVP Metadata can enrich matched rows with descriptions, people, genres, ratings, keywords, dates, and GUIDs.

4. Export With Warnings

The app writes the filled CSV/workbook and a warning report for required blanks, invalid values, SKU conflicts, and review-needed metadata.
